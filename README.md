# Adult Income Classification

This project was completed for CIS 8693: Data Analytics, AI for Digital Innovation as part of the Master of Science in Information Systems (MSIS) program at Georgia State University.

## Objective

Compare multiple classification algorithms and identify the model with the strongest predictive performance.

## Models Evaluated

- Logistic Regression
- Decision Tree
- Random Forest

Additional models, including K-Nearest Neighbors (KNN), were explored during development. The final analysis focused on Logistic Regression, Decision Tree, and Random Forest, which were included in the report and presentation.
